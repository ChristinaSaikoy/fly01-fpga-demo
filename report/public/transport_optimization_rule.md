# 从O7观察总结的传输优化核验规则

性质：工程总结／可复用案例模板，不是对话原文；不声称本轮新做了跨项目验证。

适用场景：主机与可编程硬件之间压缩、打包、事务合并等通信改动，且存在可核对的原始输入和确定性参考。

1. 固定模型、输入和采用顺序、RNG、dt、完整输出及制品身份。比较编码前后事件逐项相等，边界/非法包另列。
2. 明确整套、子阶段、单事务与每帧的计时起止。协议字数可精确计算，墙钟时延要记负载、环境和实现版本。
3. 同时报均值、P99/最长停顿、超期/重试，以及LUT/FF/BRAM/DSP代价。均值降低不代表尾部或严格实时通过。
4. 把助手主张关联到可读的原始结果，再由指定验收负责人决定接收范围，并记录其角色。保留失败与待审状态，不把后续裁决回填到旧原件。

来源：公开O7-1/O7-2/O7-4节选、指定历史O7结果及后续总控分项接收。已验证的效果仅指该指定O7制品的无损还原、完整状态核对和当时观察到的性能变化。

失效条件：模型/序列化语义或输出完整性改变、不同输入、不同制品但无身份绑定、跨时钟无同步、比较环境不一致却宣称纯因果、缺少原始记录。出现这些条件时，不能沿用历史PASS；应重新定义比较范围并验证。

不包含板卡操作授权，不绕过故障保护，不决定科学参数或新系统冻结。
