## 模型和时间边界

- 不改冻结模型、311 路名册、Q=2458、dt=20ms、全局 166700 路 RNG 消耗序列。
- PixelDirectionMVP 是新工程适配，不是 WORK-08 几何合同的放宽：处理图像左/
  右/居中对应既有 L/R/双侧刺激，初始中心带 ±2px、左右镜像显式配置。
  无弧度、米制位置、虚假标定。镜像会改变实际处理坐标，不只是美化预览。
- 视觉只替换未采用观测；已经进入模型的输入、随机数及步骤写入账本，不跳步。
  输入延迟一模型步；新输入按实际采用顺序重放，不按原始所有视频帧假造一致性。
- 接收年龄上限 250ms 是非运动展示的工程值，曝光/相机缓冲延迟始终 UNKNOWN。
  模型 dt 不等于实际墙钟步率；页面分别报告视觉帧率和模型计算率。
  250ms 输入检查发生在采样时，不是端到端保证；本次接收估计到结果 P99 约
  251.8ms、最大约262.2ms，不能用模型计算均值几毫秒宣称完整交互时延几毫秒。
- 无目标/多目标/过期清空选定刺激；中性输入不是刹车，居中不是直行保证。
  DN/动作是真实模型后处理，不从像素直接合成转向。

## UART 候选与错误处理

复用 WORK-07 的编码、CRC/长度/转义和完整状态校验器，**不修改其文件**。
新增主机流式重同步层；有效结果必须匹配操作、会话、帧、视图和代次。
保留 500ms、一次同事务重试：FRAME/ACK 等最多两次相同请求，不擅自缩短超时。
一模型步 FRAME＋ACK 的名义 I/O 等待最多 2s；任何不确定结果不进入后处理。
复位不自动重试；ACK 不确定时也不发布该步、不给出下一个神经步。

FAULT 后不自动恢复。操作者可明确选择“恢复本进程先前拥有的会话”，确认
旧会话复位后释放，建立新会话，模型、RNG、预处理器和仿真身体全部从 0 开始；
跨进程重启遇未知旧 owner 不擅自夺取。来源、代次和重新归零都有日志。

新真实板测需 Controller 提供当前候选绑定的 **新**授权和准确装载回执：旧许可
不可直接使用。Windows 原 VID/PID/PnP/拓扑/独占串口检查仍生效。另要求
`mvp_scope.name=MVP-DEMO-V1_NON_MOTION`、
`restart_policy=EXPLICIT_SAME_PROCESS_WITHIN_WINDOW` 和本次监督器开始时的
`suite_started_monotonic_ns`；授权使用记录独占绑定到进程，不能跨进程重放。
自该时刻 1795s 后禁止发起/等待新事务，给 1800s 上限预留收尾时间。
这不是已完成整套板测/计时的证明；烧录前的总监督器接续和实测仍待授权阶段完成。

历史生产 O8 bit 为 93399a70892ece88300af96cd2dd27566b683f9eeecc41f394465182b5786eb4；
