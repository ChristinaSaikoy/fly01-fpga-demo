# FLY01 R6 上位机控制台

在已有WORK19 Meshy工程上增加浏览器人工控制。默认不连接串口、不启动车轮。

当前本机地址：http://127.0.0.1:8881/ 。服务器已在后台启动，打开链接即可，不必重复启动CMD。以后重启运行start_panel.cmd，保持它在后台即可。需要Node22+、Python及pyserial；本机复用已有环境。跨机设置FLY_PYTHON为对应解释器路径。

## 使用

1. 保持成功R6接线与供电，双轮架空。若原视觉神经控制CMD仍在运行，先用Q正常停车退出，释放FPGA串口。页面是新的唯一控制入口，不能两个程序同时占端口。
2. 进入“实时控制”，勾选架空确认，点击“连接设备”。连接只发送停车S，不发E/B。自动选择唯一VID/PID=1A86:7523的FPGA UART；驱动板USB供电可接充电宝，不要求电脑枚举到驱动设备。端口异常时页面显示原因，不抢占或结束其他进程。
3. 等新鲜R6诊断/零命令ACK和无故障。移动手或物体，点击“开放动作”：持续等待有效神经结果并保持开放，直到点击“关闭动作”或触发保护。取消5秒等待到期与8秒动作到期，不发送固定PWM、不自动重新开放。
4. “关闭动作”或Esc可随时发S；没有固定动作时长上限。页面只确认零命令ACK，不证明实体轮子物理停稳。需要再次运行时手动开放。
5. “拍摄视图”隐藏技术细节；可自行F11全屏。页面切后台/离开会请求停车，后台心跳过期也停车，不自动重新使能。截屏/录屏时尽量保持页面在前台。
6. “历史回放”先请求停车，然后播放R6历史数据，并一直标明回放。回放不会启动硬件。不要把回放录屏剪成现场同步。

## 范围

- 沿用R6真实神经计算与I²C执行，电脑只发人工E/S并显示返回数据。没有改变RTL、科学模型、驱动配置或K230固件。
- 模型转角是ACKed命令固定比例示意，无编码器，非实测姿态。实际驱动物理断线后独立停车仍未验证，本页不改变架空范围。
- 只有用户点击才连接硬件；关闭页面后后台可能仍持有串口并保持停车，应点“断开设备”释放。服务进程异常终止或USB断线时不能保证最后S送达，机械开关仍可及。
- 服务仅127.0.0.1，写接口需要同源及随机令牌，命令白名单只有connect/arm/stop/disconnect/heartbeat，不接受任意PWM或B诊断。
- 新日志写runs/内独立events_*.jsonl，既有成功运行、封包和原视频未覆盖。模型、素材权利与旧包来源保持原项目规则。
